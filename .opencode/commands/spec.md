description: Start spec-driven development for a new feature or significant change
---

Invoke the `spec-driven-development` skill.

## Steps

1. Read `AGENTS.md` for project context
2. Read relevant `docs/01-BRD.md` and `docs/02-PRD.md` sections
3. Follow `.opencode/skills/spec-driven-development/SKILL.md` phases:
   - **Phase 1:** Specify (surface assumptions, write spec)
   - **Phase 2:** Plan (delegate to `planner` agent → `tasks/plan.md`)
   - **Phase 3:** Tasks (→ `tasks/todo.md`)
   - **Phase 4:** Implement (hand off to `/build`)
4. Do NOT proceed to Phase 4 without human review of spec + plan

**Output:** `tasks/plan.md` and `tasks/todo.md` committed to the repo.
